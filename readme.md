# PEHA PHC System Software Archive

Welcome to the **PEHA PHC Legacy Software Archive**. 

This repository makes legacy software versions for PEHA PHC home automation systems available once again for users, technicians, and system integrators who need to perform system updates, routine maintenance, or re-configuration on older PEHA PHC installations.

## 🛠 Usage & Prerequisites

1. **Java Runtime Environment (JRE):**  
   Certain versions of the PEHA PHC software require Java to run. If Java is not installed on your system, please install `jre-8u491-windows-x64.exe` first.

2. **System Compatibility:**  
   - Make sure you select the software version that corresponds with your installed PEHA PHC controller hardware version.
   - Run software setup files with Administrator privileges (`Right click -> Run as Administrator`).
